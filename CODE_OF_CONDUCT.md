# Code of Conduct

## Our Standards

Project participation must remain professional, respectful, and focused on constructive technical
collaboration. Expected behavior includes giving actionable feedback, respecting differing
viewpoints, protecting private repository data, and correcting mistakes promptly.

Harassment, threats, discrimination, sexualized conduct, deliberate disclosure of private
information, and sustained disruptive behavior are not acceptable.

## Enforcement

Report conduct concerns privately through the repository's GitHub security advisory reporting
channel. Do not include sensitive details in a public issue. Maintainers may edit or remove content,
close or lock discussions, reject contributions, or restrict participation when necessary.

Enforcement decisions will consider context, severity, repetition, and participant safety.
Good-faith reports will be handled as confidentially as practical.

## Scope

This code of conduct applies in repository spaces and when representing the project in public.
