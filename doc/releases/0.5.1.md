# GCA 0.5.1

[简体中文](https://github.com/PANZERLEADER/git-contribution-analyzer/blob/v0.5.1/doc/zh-CN/release-0.5.1.md)

## Fixes

- Apply additive SQLite migrations when `status`, `doctor`, `sync` or `index` opens an existing
  workspace. Workspaces created by 0.2.0 through 0.4.1 can therefore populate 0.5.x structural
  facts without rerunning `gca init`.
- Preserve confirmed identities and active reversible identity merges during incremental sync and
  full index rebuilds. Explicit alias ownership is no longer reset when a known Git author is read
  again.
- Refresh `toolVersion`, `updatedAt` and `lastSync` metadata after a successful index operation.
- Generate combined GitHub Release notes with explicit UTF-8 validation and tag-pinned language
  links so English and Simplified Chinese pages remain readable from the Release page.

## Compatibility And Upgrade

- This is an additive patch over 0.5.0. CLI commands, report schemas, structural rule versions and
  assessment/ranking/resume behavior remain unchanged.
- Run `gca index <repo>` after upgrading. Existing identity mappings and reversible merge events are
  retained while structural facts are rebuilt.
- Historical structural baselines remain observation-only and do not affect difficulty or resume
  claims.

## Validation

- Regression tests cover migration through `status`, `doctor` and `index`, plus identity-merge
  preservation across both `sync` and full `index`.
- Windows/Linux/macOS quality, GUI, credential-history and release-artifact checks remain required
  before publication.
