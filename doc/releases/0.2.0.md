# GCA 0.2.0

[简体中文](../zh-CN/release-0.2.0.md)

## Highlights

- Select multiple confirmed people explicitly, or assess all active confirmed human identities
  with explicit exclusions.
- Preview, execute, list, and reverse identity merges without deleting Person records or rewriting
  historical runs. Manual alias reassignment now records reversible `ALIAS_MAP` events.
- Produce deterministic dense rankings for workload, difficulty, and delivery. An optional,
  explicit YAML configuration enables cohort-normalized Decimal composite scores.
- Persist `work-assessment/v2` reports and export them as UTF-8 BOM CSV. Email remains excluded
  unless `--include-email` is supplied.

## Compatibility And Upgrade

- Frozen `work-assessment/v1` JSON and Markdown reports remain replayable.
- Migration `0006_identity_merges` adds reversible identity state. Downgrade is allowed after all
  active merge events have been reversed.
- Existing `identities map` parameters and JSON envelope remain compatible.
- Historical analysis and assessment run payloads are immutable.

## Privacy And Interpretation

- Ranking fields are deterministic and are not sent to or modified by LLM Providers.
- CSV omits email by default, and selection exclusions record reasons without adding excluded
  people to the report cohort.
- Rankings are review aids within one cohort. They do not establish employee value, working hours,
  compensation, promotion readiness, or business outcome.

## Release Gates

The release commit must pass the Windows, Linux, and macOS CI matrix, credential-history scan,
isolated wheel lifecycle, pipx installation, and standalone artifact smoke tests. The tagged
workflow publishes SHA-256 checksums and uses this file as the `v0.2.0` release notes.
