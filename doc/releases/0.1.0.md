# GCA 0.1.0

## Scope

The first release provides a local CLI for Git indexing, identity confirmation, deterministic
contribution analysis, completed-work size/difficulty assessment and evidence-backed resume drafts.
LLM wording is optional and provider-neutral.

## Installation Paths

- Python wheel or source distribution for Python 3.12/3.13.
- `pipx` installation from the wheel.
- Standalone Windows, Linux and macOS artifacts built by release CI.

See `doc/guides/installation.md` for commands and rollback guidance.

## Compatibility

- Existing `ANALYSIS` runs remain readable.
- Migration `0005_run_types` upgrades historical rows to `ANALYSIS` and supports downgrade to
  `0004_llm_audit`.
- Legacy `semantic.resumeBullets` remains readable during the 1.x line but is deprecated.
- Workload and difficulty rules are versioned; historical run JSON is never rewritten.

## Security And Privacy

- Deterministic no-LLM operation is complete.
- Provider credentials are environment-only.
- Provider prompts are redacted and Evidence-allowlisted.
- CI scans Git history for leaked credentials and verifies wheel installation in isolation.

## Known Limitations

- Structural complexity/call-impact adapters are post-MVP; reports expose a gap and lower
  confidence when unavailable.
- Git evidence cannot prove working hours, sole ownership or business outcomes.
- Squash merges without preserved patch evidence are associated conservatively.
- The tagged three-platform workflow builds and smoke-tests all release artifacts.

## Release Checklist

- [x] Three-platform CI and standalone jobs pass for the release commit.
- [x] Wheel/sdist and standalone artifacts are retained.
- [x] Credential scan passes.
- [x] Version is `0.1.0` on the approved release commit.
