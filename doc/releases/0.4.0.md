# GCA 0.4.0

[简体中文](https://github.com/PANZERLEADER/git-contribution-analyzer/blob/v0.4.0/doc/zh-CN/release-0.4.0.md)

GCA 0.4.0 adds an optional cross-platform desktop application built with PySide6 and QML.

## Highlights

- Add the independent `gca-gui` entry point while retaining the `gca` CLI.
- Add repository lifecycle, assessment, trends, people, work-item/Evidence, run comparison,
  report export, resume and Provider views.
- Run Git, SQLite and Provider work outside the Qt UI thread with per-repository FIFO scheduling.
- Add cooperative progress/cancellation contracts and terminalize cancelled assessment runs.
- Share system-time-zone boundary parsing between CLI and GUI, including `since <= until`
  validation.
- Add optional `[gui]` packaging and Windows/Linux/macOS PyInstaller release artifacts.

## Compatibility

The core wheel does not depend on PySide6. Existing CLI commands, JSON report contracts and
repository-local SQLite schema remain compatible. GUI settings contain only non-sensitive local
preferences; Provider credentials remain environment variables or authenticated CLI sessions.
