# GCA 0.4.1

GCA 0.4.1 fixes CLI standalone packaging after the optional desktop GUI was introduced.

## Fixes

- Exclude the Qt adapter, QML resources, PySide6 and shiboken6 from `gca` CLI standalone builds.
- Verify the final CLI PyInstaller archive and fail release builds if GUI runtime entries are found.
- Keep framework-independent GUI request DTOs available where shared package exports require them.
- Read the macOS application bundle version directly from `pyproject.toml`.

## Compatibility

There are no CLI command, report schema, SQLite schema or GUI workflow changes in this patch.
The core wheel remains free of PySide6. Users of `0.4.0` standalone CLI artifacts should upgrade to
`0.4.1`; GUI artifacts remain functionally equivalent.
